# Portfolio Website - Rishav Mishra

Welcome to your personal portfolio website! This project is designed to be modern, responsive, and visually appealing, featuring a dark theme with glassmorphism effects and smooth animations.

## 🚀 Getting Started

### Prerequisites

- A code editor (like VS Code).
- Basic understanding of Git (since you are managing it!).

### Running Locally

1.  **VS Code Live Server:**
    - Open this folder in VS Code.
    - Install the "Live Server" extension if you haven't already.
    - Right-click on `index.html` and select "Open with Live Server".

2.  **Double Click:**
    - You can simply double-click `index.html` to open it in your browser, though some features might work better on a local server.

## 📦 Deployment to GitHub Pages

Since you want to host this as `RishavMishraRM.github.io`:

1.  **Create Repository:**
    - Go to GitHub and create a new repository named **exactly**: `RishavMishraRM.github.io`.
    
2.  **Push Code:**
    - Initialize git in this folder (if not done): `git init`
    - Add files: `git add .`
    - Commit: `git commit -m "Initial commit"`
    - Add remote: `git remote add origin https://github.com/RishavMishraRM/RishavMishraRM.github.io.git`
    - Push: `git push -u origin main` (or `master` depending on your default branch).

3.  **Live Site:**
    - Once pushed, GitHub will automatically look for `index.html` in the root.
    - Your site should be live at `https://RishavMishraRM.github.io` within a few minutes.

## 🎨 Customizing

-   **Content**: Edit `index.html` to update specific text, links, and project details.
-   **Styles**: Tweaking colors is easy! Open `style.css` and change the `--hue` variable at the top to shift the entire color theme.
-   **Images**: Replace placeholder images or SVGs as needed.

-   **HTML5**: Semantic structure.
-   **CSS3**: Custom properties, Flexbox/Grid, Animations.
-   **JavaScript**: DOM manipulation for the mobile menu and cursor effects.
-   **Font Awesome**: Icons.
